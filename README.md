# Finance Manager API

## Project Overview
A modern Spring Boot REST API for personal finance management.

## Features
    ✔ Expense Management
    ✔ Categories
    ✔ Validation
    ✔ Exception Handling
    ✔ Swagger Documentation

### Current Features
    - Manage expenses
    - CRUD operations for expenses
    - Request validation
    - Global exception handling

    - Unit tests
    - Integration tests

    Docker
